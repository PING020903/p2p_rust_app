# 新手测试指南（P2P 聊天联机测试）

> 本文档帮你从零开始：安装 Rust → 编译工程 → 运行程序 → 和测试伙伴互相连接聊天。
> 全程只要**照着做**，看到 `看到 XXX 即成功` 这样的提示就说明你做对了。

---

## 第 1 步：安装 Rust（约 10 分钟）

1. 用浏览器打开官网下载页：<https://rustup.rs>
2. 点页面里的 **64 位下载**（`rustup-init.exe`），保存到桌面
3. **双击** `rustup-init.exe` 运行
4. 出现命令行窗口时，直接按 **回车**（选默认安装），等它装完（会下载，需要几分钟，期间保持联网）
5. 装完后**关掉这个窗口**，重新打开一个新的 PowerShell 窗口

> 新开窗口的方法：按 `Win 键`，输入 `powershell`，回车。

6. 在 PowerShell 里输入下面两行，**回车**，看到版本号就成功了：

```powershell
cargo --version
rustc --version
```

```
看到类似：cargo 1.xx.x / rustc 1.xx.x 即成功
```

> 如果提示"找不到 cargo"：关掉所有窗口，重开 PowerShell 再试；还不行就重启电脑。

---

## 第 2 步：拿到工程源码

让测试伙伴把**工程文件夹打包成 zip** 发给你（zip 里不需要 `target` 文件夹）。

1. 把 zip 解压到一个**简单路径**，比如 `C:\p2p_rust_app`
2. PowerShell 里进入工程目录（路径按你实际解压的位置改）：

```powershell
cd C:\p2p_rust_app
```

> 小技巧：输入 `cd ` 后把文件夹直接**拖进** PowerShell 窗口，会自动填好路径，回车即可。

---

## 第 3 步：编译（首次较慢）

在工程目录下输入：

```powershell
cargo build --release
```

- 首次编译会下载一堆依赖，**需要几分钟**，耐心等，不要关窗口
- 编译期间如果报"网络错误"类提示，等一会儿再执行一次
- 看到最后的 `Finished` 字样就是成功了：

```
看到 Finished `release` profile ... 即成功
```

编译产物在 `target\release\p2p_rust_app.exe`。

---

## 第 4 步：运行程序

```powershell
.\target\release\p2p_rust_app.exe
```

会看到主菜单：

```
=== 主菜单 ===
  1. 计算器
  2. 学生信息管理
  3. 彩色打印演示
  4. P2P 聊天
  q. 退出
> 
```

输入 `4`，回车，进入 P2P 聊天。

```
看到 [角色登录] 菜单即成功
```

---

## 第 5 步：登录身份

两种方式，**推荐用方式 A**（测试伙伴会给你一个助记词）。

### 方式 A：用伙伴给的助记词登录（推荐）

1. 输入 `r`，回车
2. 看到"助记词"提示后，**粘贴伙伴给的助记词**（12 个英文单词，空格隔开），回车
3. 依次输入并回车：
   - `姓名`：随便填，比如 `小张`
   - `生日`：必须 `YYYY-MM-DD` 格式，比如 `2000-01-01`
   - `性别`：`男/M`、`女/F` 或 `保密/O`
   - `密码`：8 位以上，比如 `test123456`（**记牢，下次登录要用**）

```
看到 登录成功: 小张 ... 即成功
```

### 方式 B：自己新建身份

1. 输入 `0`，回车
2. 屏幕上会显示你的**助记词（12 个英文词）——一定要抄下来保存好**，这是你身份的唯一备份
3. 按提示输入助记词前几个词确认，然后填姓名/生日/性别/密码

> 两种方式都会把身份保存在 `C:\Users\你的用户名\.p2p_rust_app` 文件夹里。

---

## 第 6 步：找到你的直连地址

登录后往下看启动信息，找到这一行：

```
全局IPv6直连地址（任选一条分享，对方 /dial 即连；需路由器放行该端口）:
  /ip6/2409:xxxxxxxx.../tcp/xxxx/p2p/12D3KooW...
```

- **把 `  /ip6/...` 这一整段复制**（前面两个空格别复制，从 `/ip6` 开始到末尾 `...12D3KooW` 全部都要）
- 如果刚才刷屏没看到，输入 `/listen` 回车会重新打印
- 把这段地址**发给测试伙伴**（微信等）

```
看到 /ip6/2409... 开头的地址行即成功
```

> 如果提示"本机暂无全局 IPv6"：说明电脑或路由器没开 IPv6，见文末"常见问题"第 3 条。

---

## 第 7 步：连接对方

1. 测试伙伴也会把他的地址发给你，同样是一段 `/ip6/...` 开头、`/p2p/...` 结尾的长地址
2. 输入 `/dial `（注意 `/dial` 后面有个**空格**），然后**粘贴**对方地址，回车：

```
/dial /ip6/2409:xxxx.../tcp/xxxx/p2p/12D3KooW...
```

```
看到 已连接对端: ... 即连接成功
```

3. 连接成功后，**直接打字回车**就能发消息：

```
你好，收到吗？
```

```
看到 [对方] 你好，收到吗？ 说明你收到了对方的回复，双向互通成功！
```

> 若没收到对方消息，可先输入 `/chat 对方名字` 回车聚焦，再发消息。

---

## 第 8 步：传文件（可选）

1. 先建立信任（首次连接时按提示核对对方身份，或输入 `/trust 对方名字`）
2. 发送文件：

```
/send 对方名字 C:\测试文件.txt
```

```
看到 开始发送 ... 等待对方确认 / 对方已开始接收 即开始传输
看到 文件接收完成 / 文件发送完成 即传输完成
```

接收的文件会保存到你电脑的**下载文件夹**（默认 `C:\Users\你的用户名\Downloads`）。

---

## 退出

- 聊天界面：输入 `/q` 回车
- 回到主菜单：输入 `q` 回车

---

## 常见问题

### 1. 编译报错 / 很慢
- 先执行 `cargo update` 再重新 `cargo build --release`
- 确认电脑能正常上网（需要能访问 crates.io 仓库）

### 2. 连接失败 / 拨号无响应
按顺序检查（**双方都要做**）：

1. **被连接那一方**的路由器要放行该端口：
   - 登录路由器管理页（一般 `192.168.1.1` 或 `192.168.31.1`）
   - 找 **IPv6 设置 / 防火墙 / 安全** 相关页面
   - 放行程序显示的 TCP 端口（如 `5229`），或者**临时关闭 IPv6 防火墙**测试
   - 路由器品牌型号不同，找不到就在网上搜"你的路由器型号 + IPv6 防火墙"
2. **Windows 防火墙**：首次运行程序时若弹出"允许访问网络"，选**允许**；若没弹，检查"Windows 安全中心 → 防火墙 → 允许应用通过防火墙"里有没有 `p2p_rust_app`

### 3. 没有全局 IPv6 地址
- 电脑上检查：PowerShell 输入 `Get-NetIPAddress -AddressFamily IPv6`，看有没有以 `2408`、`2409` 开头的地址
- 没有的话：进路由器管理页，打开 **IPv6**（设为 DHCP/自动），电脑连网后一般会自动获得

### 4. 之前能连，现在连不上了
- IPv6 的"临时地址"会定期更换，让对方重新 `/listen`，把最新地址发给你再拨

### 5. 忘记登录密码
- 身份文件在 `C:\Users\你的用户名\.p2p_rust_app`，删掉里面的 `.key` 文件后用**助记词**重新登录（第 5 步方式 A）

---

## 给测试伙伴的配合检查清单

- [ ] 双方都确认电脑有全局 IPv6（程序里能看到 `全局IPv6直连地址`）
- [ ] 双方路由器 IPv6 防火墙放行各自端口（或临时关闭）
- [ ] 双方互相把 `/ip6/...` 地址发给对方
- [ ] 一方 `/dial` 对方地址，看到 `已连接对端` 后双向发消息
- [ ] 传文件测试前，双方先 `/trust` 建立信任
